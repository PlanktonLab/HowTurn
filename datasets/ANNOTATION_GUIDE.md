# 標註規範 — 機車待轉格（航拍影像 / YOLO OBB）

這份文件記錄 DieTurn 訓練資料是怎麼標出來的：影像怎麼取樣、類別怎麼定義、框怎麼畫、用什麼工具匯出。

**影像與標註檔本身不在這個 repo 裡**（見下方「為什麼沒有附影像」），只留這份規範。要重建一套等價的訓練資料，照這份文件做即可。

## 影像取樣

| `C_taipei_hills_hires` | 40 | 同 A | 同 A | 北投／士林／文山山區道路與小路口 | 高解析負樣本 |
| `D_rural_nlsc` | 80 | 同 B | 同 B | 雲林、屏東、台南、宜蘭、花蓮、苗栗鄉間道路與路口 | 低解析負樣本 |

取樣點是 OSM 的號誌節點；每張圖是以該點為中心的 4×4 瓦片拼接（抓圖邏輯見 `imagery/fetch_taipei.py`）。

C 與 D 是「預期沒有待轉格」，不是「保證沒有」。看到就照標，不要因為它在負樣本組就跳過。

320 張平均分給 4 位標註者，每人 80 張，各自一個 `labeler_N/` 目錄。

## 類別定義

- `0 waiting_zone` **機車待轉格**：白色細線矩形框，通常在路口右側、緊貼行人穿越道前方，長邊順著你要待轉的那條路。大路口常一個角落一格，四個角落最多四格。有些框內有「機車待轉區」字樣或斜線，航拍看不清楚沒關係，框本身就算。
- `1 other_box` **其他白色矩形框**：機車停等區（橫跨整個車道、在停止線與斑馬線之間的大框）、公車停靠區、路邊停車格、卸貨區等。標這類是為了讓模型學會分辨「是矩形框但不是待轉格」。不確定屬於哪一類時，標 `other_box` 並留備註。

不需要標：斑馬線、車道線、導引箭頭、網狀線、停止線。

> v1 實際回收的標註全部是 class 0（211 個框），`other_box` 沒有被用到。下游的 `ml/prepare_dataset.py` 因此只接受單一類別，收到 class 1 會直接報錯。要沿用兩類設計的話，那邊要一併改。

## 畫框規則

- 用**旋轉框**（四點）而不是水平框 —— 待轉格會隨路口方向旋轉。輸出格式為 YOLO OBB：每行 `class x1 y1 x2 y2 x3 y3 x4 y4`，座標 0–1 正規化，共 9 個欄位。
- 框貼著白線外緣，不要包到旁邊的斑馬線。
- 部分被機車、車輛或樹影遮住的待轉格照樣標，只要你能確定框的範圍。完全看不到的不標。
- 影像四邊被切到一半的待轉格，露出超過一半就標。
- 一張圖沒有任何目標，就存一個空的標註檔 —— 不要漏掉這張，它是有價值的背景負樣本（`prepare_dataset.py` 會把沒有對應標註檔的圖當成純背景）。

## 標註工具：CVAT

1. 建一個 Project，Labels 依序加 `waiting_zone`、`other_box`（順序要和類別編號一致）。
2. 每人各建一個 Task（或一個 Task 四個 Job），上傳自己那 80 張圖。
3. 畫框：左側工具列選 **Rectangle**，Drawing method 選 **By 2 points**，模式 **Shape**（不是 Track）。拉出框後點選它，框上方會出現圓形旋轉把手，拖動它貼合白線；按住 Shift 以 15 度為單位吸附。
4. **不要用 Polygon 畫待轉格** —— CVAT 的 OBB 匯出只認「旋轉過的矩形」，多邊形匯不出來。
5. 常用快捷鍵：`N` 開始畫框、`Ctrl+S` 存檔、`F` / `D` 下一張／上一張、`Ctrl+Z` 復原。
6. 標完在 Task 頁面 Actions → **Export task dataset**，格式選 **Ultralytics YOLO Oriented Bounding Boxes 1.0**。

匯出結構即 `ml/prepare_dataset.py` 預期的輸入：

```
datasets/labeled/labeler_N/
  images/<stem>.jpg
  labels/train/<stem>.txt
  data.yaml
```

## 已知雜訊

- 台北市影像（A、C）上有「臺北市政府都市發展局」半透明浮水印，位置固定重複。標註時直接忽略；訓練時它是均勻分布的背景雜訊，對兩類都不會有偏差。
- 部分 A 類影像的路口不在正中央 —— OSM 的號誌節點常標在某一支路上而非路口中心。只要待轉格有進到畫面就照標。
- 每張圖的中心經緯度有記錄在分發用的 `manifest.csv`，可貼到地圖服務用街景確認現場（只是看，不要拿別家的圖來標）。

## 為什麼沒有附影像

- **臺北市政府都市發展局 WMTS**（A、C 共 200 張）：使用對象不限，但不得批次大量取圖、不得轉供第三方流通。因此這批影像只留在本機，不隨 repo 散布。
- **內政部國土測繪中心 WMTS**（B、D 共 120 張）：政府資料開放授權條款第 1 版，可重製、改作、商用，須註明出處「內政部國土測繪中心」。

要自行重建資料集，請依上表的來源、zoom 與取樣方式，自 各來源官方服務取得影像後再行標註。
